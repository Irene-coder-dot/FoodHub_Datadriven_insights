# 🍔 FoodHub Data Analysis

## 📌 Project Overview
This project explores customer ordering behavior, pricing trends, and restaurant performance using FoodHub data.

The goal is to generate insights that can help improve business decisions for a food delivery platform.

## 🎯 Business Questions
- What are the most popular restaurants?
- How does pricing affect customer orders?
- Which cuisines are most preferred?
- When do customers order the most?

## 🛠️ Tools Used
- Python
- Pandas
- Matplotlib / Seaborn

## 🔍 Key Insights
- Most customers are price-sensitive, with orders below $20
- A few restaurants dominate total orders (strong brand loyalty)
- American and Japanese cuisines are most popular
- Weekend orders are significantly higher than weekdays
